add_function(my_func, **kwargs)[source]#

Adds a function to the calculation process

The user can create his own function to calculate a new parameter from the points given in the pulse_number_GITT, pulse_number_ICI or pulse_number_HPPC documentation.

The new custom function must be an argument of process_file, as detailled in the example.

Then, the new parameter is calculated and stored in the result DataFrame and plotted over SOC.

Parameters:

  • my_func (function) – Function to add to the calculation process

  • **kwargs (dict) –

    Keyword arguments to pass to the function. The parameters available are:

    • Specific parameters defined in pulse_number_GITT,

    pulse_number_ICI or pulse_number_HPPC : float values,

    • Voltage, Current and Capacity : interpolation functions of time,

    • df_pulse : DataFrame containing the pulse’s data,

    • State : ‘C’ or ‘D’ corresponding to the charging state of the pulse.

Returns:

New parameter calculated by the function my_func

Return type:

float

...     Internal_resistance = (Voltage(t0 + 1) - Voltage(t0)) / Ipulse
...     return Internal_resistance
