.. py:function:: process_file(file_path, column_names=None, cycle=None, debug_func=None, my_func_list=[], save=False, png=False)

   Processes the data for a given file in .parquet or .csv format

   It detects the type of tests applied to the battery and process the data for each type of tests

   :param file_path: Path to the file to process
   :type file_path: str
   :param column_names: Dictionary containing the column names to be used for the analysis
                        The useful columns are: Voltage, Current, and SysTime (system time or test time) that should be values and the real column names should be their keys
   :type column_names: Dict, optional
   :param cycle: List of cycle numbers to process
   :type cycle: int, optional
   :param debug_func: Function to be called during the preprocessing of the data to debug a file
   :type debug_func: function, optional
   :param my_func_list: List of functions to add to the calculation process
   :type my_func_list: list, optional
   :param save: Whether to save the result plots in format .html (default is False).
   :type save: bool, optional
   :param png: Whether to save the result plots as png files (default is False).
   :type png: bool, optional

   :returns: * **df** (*pandas.DataFrame*) -- DataFrame containing the processed data.
             * **result_dict** (*dict*) -- Dictionary containing the processed results for each test type.
               Keys are test names ('GITT', 'ICI', 'HPPC') and values are DataFrames with the respective results for each test.

.. py:function:: find_test(df_input)

   Finds the test applied to the battery

   Analyses the test type for each cycle according to its current pulses number
   It needs the preprocessed data with in particular the columns Cycle, State and normcurrent

   :returns: DataFrame containing the preprocessed data.
   :rtype: pandas.DataFrame


.. py:function:: process_dqdv(df, file_path, heatmap=False, save=False, png=False)

   Processes the CCCV data for a given preprocessed file

   Plots the dQ/dV curves and the dQ/dV heatmap for every cycles

   :param df: DataFrame containing the CCCV data to process.
   :type df: pandas.DataFrame
   :param file_path: Path to the file to process.
   :type file_path: str
   :param heatmap: Whether to plot the dQ/dV heatmap (default is False).
   :type heatmap: bool, optional
   :param save: Whether to save the plots in format .html(default is False).
   :type save: bool, optional
   :param png: Whether to save the plots as png files (default is False).
   :type png: bool, optional

   :returns: DataFrame containing the dQ/dV data.
   :rtype: pandas.DataFrame
