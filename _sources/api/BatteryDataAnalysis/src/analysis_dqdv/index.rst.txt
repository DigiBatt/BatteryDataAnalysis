.. py:function:: calculate_dqdv_for_one_cycle(df, smoothing=True, sigma=None)

   Calculate dQ/dV for a specific cycle from a dataframe using columns 'Voltage' and 'Capacity'.

   :param df: DataFrame containing the data of a specific cycle with the columns 'Voltage' and 'Capacity'
   :type df: pandas.DataFrame
   :param smoothing: Whether to smooth the dQ/dV curve
   :type smoothing: boolean, optional
   :param sigma: Standard deviation of the Gaussian filter to use for smoothing to control manually the smoothing
   :type sigma: float, optional

   :returns: * **df_smoothed** (*pandas.DataFrame*) -- DataFrame containing the smoothed dQ/dV curve
             * **sigma** (*float*) -- Sigma parameter used for the smoothing
